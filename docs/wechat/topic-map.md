# 微信文章主题地图

## 数据研发

关注业务过程、粒度、主键、复用、质量、调度、性能和发布。转译到 MaxCompute＋Dataphin 时，优先形成模型设计、字段映射、依赖图、SQL 草案和回退方案。

## 资产检索答疑

关注“需求对应哪些资产、负责人是谁、口径是否批准、血缘是否新鲜”。输出必须带资产 ID、版本、来源和权限判断，不能只返回相似表名。

## 数据分析

关注从业务问题到指标、维度、异常、归因和行动。分析结果分为已知事实、异常线索、待验证假设和建议动作，并保留引用和数据快照。

## 数据 Agent

关注语义层、工具调用、Harness、只读执行、预算、轨迹、评测和人工审批。模型负责规划与解释，受控工具负责查询和证据，生产变更由平台和人工确认。
