# 知识域桥接层

桥接层只说明两个知识域如何协作，不把它们合并。

## 两个域的职责

- [`docs/wechat/`](../wechat/README.md)：经验来源和文章证据，回答“文章提出了什么”。
- [`docs/ossie/`](../ossie/README.md)：OSI/Ossie 规范学习，回答“语义模型、本体和映射的结构约束是什么”。
- [`docs/bridge/`](README.md)：工程落地，回答“哪些文章观点可以映射到哪些已批准语义、资产和工具”。

## 桥接规则

1. 微信文章不能改变 Ossie 规范的定义。
2. Ossie 规范不能反向证明公众号文章已被完整阅读。
3. 文章观点要进入生产建议，必须经过语义/本体映射、权限审查和评测。
4. 资产事实、业务批准口径和模型建议分别存证，不能用摘要互相替代。

推荐链路：

`微信文章证据 → 工程假设 → Ossie/语义映射 → MaxCompute/Dataphin 工具契约 → 评测与人工批准`
