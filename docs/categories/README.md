# 微信知识分类视图

分类是查看入口，不是来源层。每张知识卡必须回指 `sources/wechat-observations.json` 的记录 ID 和证据等级。

- [数据研发](数据研发.md)：模型、SQL、质量、调度、发布和优化。
- [资产检索答疑](资产检索答疑.md)：资产发现、口径、血缘、责任人与权限。
- [数据分析](数据分析.md)：事实、异常、归因、假设和行动。
- [数据 Agent](数据agent.md)：语义、工具、Harness、评测和审批。

同一篇文章允许多标签，但只能有一个主分类。标题可见、局部窗口阅读、完整正文和公开转载是不同证据等级，分类页不得抹平这个差异。
