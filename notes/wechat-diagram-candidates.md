## 一图讲清 4A 架构

图示按四层展开：业务架构、数据架构、应用架构、技术架构；每层还拆出能力/组件/接口或基础设施。可作为后续 MaxCompute＋Dataphin 方案的核对框架：业务域与流程先定边界，数据层定义资产与口径，应用层承载查询/分析/Agent 入口，技术层提供计算、存储、接口和治理底座。

## 一张图看懂 Data Agent 全流程

图示可辨识的流程包括：业务用户提出问题 → 需求理解与任务拆解 → 语义/指标识别 → 资产或数据查询 → SQL 生成与执行 → 结果校验/解释 → 交付结论与复盘。该线索与本项目的“需求与口径 → 资产发现 → SQL → 验证 → 交付”链路相符，但具体步骤、工具和评测指标必须等正文核验。

## 数据质量没问题，为什么 AI 还是总答错

海报呈现至少五层质量：来源质量、表示质量、语义质量、检索质量、以及与 AI 输出相关的可引用/可追溯/可审计条件。它提示不能只检查字段空值和任务成功，还要检查语义、版本、权限和证据链；目前仅作候选假设。
