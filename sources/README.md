## 恢复公众号采集的操作规程

1. 用受支持的原生 UI 控制重新验证点击、滚动和正文读取；不读取微信私有数据库，不绕过登录或访问限制。
2. 进入已关注公众号列表逐页枚举：记录账号名称、账号公开标识（若可见）、相关性、保留/排除依据和检查状态。
3. 每个保留账号从新到旧检查至 2026-05-01，记录最早/最晚检查日期和页码/游标；经典材料可单独标记。
4. 每篇候选按公开原文 URL（去跟踪参数但保留微信文章身份参数）去重，另外检查标题/作者/日期的转载关系；保留原出处。
5. 只有正文实际可读才记为 `read`；标题可见记 `title_only`；失效/付费/验证阻塞分别记状态。公开搜索未找到不等于文章不存在。
6. 每篇写原创知识卡：问题、机制、适用条件、限制、证据、可复现实验、主分类与标签。主张与推论分开。
7. 导入后运行索引验证器，人工抽查分类；更新覆盖统计后再提交。

## 文章记录接口

必填：`id,title,publisher,published_date,url,read_status,primary_category,tags,summary`。
日期未知使用 null 并写 `date_note`；分类限定四类；禁止伪造缺失日期/链接。`read` 必须有正文阅读证据说明。账号关系和个人关注偏好只在此私有库维护，不转发公开。
